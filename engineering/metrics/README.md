# 指标记录规则

公开指标必须附带 commit、平台、任务集、provider/model 标识、重复次数、执行命令和原始 artifact 相对路径。失败运行不得静默删除；基础设施失败需单独分类。

核心指标：任务成功率、轨迹合规率、非法工具调用率、权限违规数、平均工具步骤、每个成功任务 token、P50/P95 时延，以及 worker 完成/超时/取消结果。
# 指标口径

当前可复核指标：固定 12 题确定性 harness 为 12/12 通过，轨迹合规率 100%。该结果验证评测器、工具边界和断言链路，不等价于真实模型能力。

2026-08-11 的单题真实提供商冒烟在第一次模型调用时因认证失败终止，没有产生模型能力指标。详见 [INC-0004](../incidents/INC-0004-live-provider-auth-block.md)。
