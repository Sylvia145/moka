# 迭代路线

项目定位为面向代码仓库的本地 Agent Runtime。本轮只实现三个可测、可复盘的工程增强：轨迹评测、stdio MCP 网关和可靠 worker。

## 范围边界

- 不建设 Web 控制台、线上评测平台、分布式任务队列或远程 worker。
- MCP 第一版只支持 stdio，不支持 HTTP、SSE、A2A 或 MCP 市场。
- worker 不实现自动解决 Git 冲突、进程崩溃后自动续跑或线程强杀。
- 新增和修改代码必须通过对应测试与 Ruff；历史存量 lint 仅记录，不作为本轮清理目标。

## 验收结果

| 阶段 | 完成条件 |
| --- | --- |
| 基线 | 已完成：12 题确定性 harness 建立；Windows 时区/解释器问题修复，存量跨平台限制已隔离。 |
| 轨迹评测 | 已完成：固定任务产出结果、轨迹合规与 verifier 证据；真实模型正式指标待认证恢复。 |
| MCP 网关 | 已完成：外部 stdio 工具经统一执行、权限和证据链路调用。 |
| 可靠 worker | 已完成：timeout、取消、并发限制、结构化结果和写入隔离均有验收。 |

## 后续触发条件

只有在有效的本地 provider 凭据可用后，才运行多题、多次真实模型评测；届时将报告样本数、模型版本、通过率、轨迹合规率与失败分类，避免把确定性 harness 的结果误用为模型能力结论。
