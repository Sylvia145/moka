# ADR-006：远程 MCP 写工具采用结果未知而非自动重试

## 决策

对 `initialize`、`tools/list` 等读取或握手操作允许有限重试；对所有 `tools/call` 默认不自动重试。网络超时、连接中断或 5xx 后，Moka 返回 `mcp_outcome_unknown`，提示远端工具可能已执行。

## 背景

远程请求发送成功后断开连接时，客户端无法判断服务端是否已完成操作。若工具是创建工单、触发发布或写入数据，直接重试可能导致重复副作用。

## 取舍

- 无差别重试：可提高表面成功率，但会重复执行写操作；
- 无差别不重试：最安全，但读取服务的瞬时网络失败也无法恢复；
- 按调用语义分级：读取路径可恢复，写路径保留不确定结果。

选择按调用语义分级。只有未来服务端提供可靠幂等键契约时，才允许对特定写工具增加安全重试。

## 验证

失败注入测试让远端工具在接收请求后超时，断言工具只收到一次调用，且 Agent Trace 保留 `mcp_outcome_unknown` 错误码。
