# ADR-003：确定性回归与真实模型实验双轨运行

## 决策

确定性测试负责验证 runtime 合同和失败路径；真实模型 dogfood 负责验证业务任务实际完成情况。两者分开统计，不相互替代。

## 原因

脚本化模型可以稳定覆盖 timeout、越权、worktree 和 verifier 边界，但无法证明真实模型会选择正确工具。真实模型结果会受模型版本、服务端状态和随机性影响，因此需要固定数据集、模型版本、重复次数和原始 artifact。

## 口径

- 业务 dogfood：4 个场景、每场景 3 次。
- 固定 benchmark：12 题、每题 3 次。
- 统计成功率、轨迹合规率、工具步数、时延、token（可用时）和失败分类。
- 模型或 runtime 修复后，相关实验完整重跑；不只保留最好一次。
