# 上下文压缩成对评测

> 最近一次运行：2026-08-29。此结果是 scripted、确定性 token 估算 proxy，不是模型供应商账单或真实模型成本结论。

## 目的与口径

同一任务分别以 `no_context_reduction`（控制组）和 `full_orchestrator`（实验组，开启确定性上下文压缩）运行。每个任务各执行一次，使用同一 scripted 输出与外部 Verifier。输入 token 取运行 Trace 的估算值；降幅按 `(实验组 - 控制组) / 控制组` 计算。

## 复现

```bash
uv run python scripts/run_context_compression_benchmark.py --output-dir artifacts/context-compression-benchmark-20260829
```

产物为 `results.json` 与 `report.md`；本地 `artifacts/` 保持忽略，不作为版本化性能基线。

## 结果

| 任务 | 控制组估算输入 tokens | 压缩组估算输入 tokens | 降幅 | Verifier |
| --- | ---: | ---: | ---: | --- |
| 多文件重构 | 50,004 | 18,863 | 62.28% | 通过 |
| Debug 修复 | 37,965 | 14,687 | 61.31% | 通过 |
| 接口新增与测试 | 67,895 | 22,475 | 66.90% | 通过 |
| 配置迁移 | 47,417 | 18,108 | 61.81% | 通过 |
| 依赖升级 | 57,709 | 21,734 | 62.34% | 通过 |

- Verifier：5/5 无回归；质量回归数为 0。
- 中位输入降幅：62.28%；范围：61.31%–66.90%。
- 任务均值：52,198 → 19,173 tokens，平均净降幅 63.27%。

## 限制

- 任务、输出和上下文都由 scripted fixture 固定，结果衡量的是该评测集上的上下文长度变化。
- 不含真实 provider usage、缓存计费或网络重试成本，不能表述为真实账单节省。
- 每任务当前只有 1 次运行；若引入随机真实模型，应增加重复次数并报告置信区间与失败样本。
