# 可审计分层经验记忆

Moka 将 L0 当前回合、L1 工作记忆、L2 情节记忆、L3 事实记忆和 L4 经验记忆接入 Session、Trace、文件锚点和验证结果。Trace/report 保存运行事实；持久记忆保存结论及可回查引用。

## 复现

```powershell
.venv\Scripts\python.exe -m pytest tests/test_memory.py tests/test_metrics.py -q
.venv\Scripts\python.exe -m pico.evaluation.metrics --run memory_evidence
```

`memory_evidence_v2` 覆盖 14 个固定场景：三类有效召回、无关拒绝、锚点过期、scope 越界、替代、密钥、提示注入、缺失验证、无证据弃答、并发晋升、半写入恢复与 Dream 门禁。原始 Trace/report 仅保留在忽略的 artifact 目录。

## 口径与限制

通过率、证据覆盖率与拦截率属于确定性本地合同；注入 token 为文本长度估算，不能等同供应商账单 token。词法检索保证可解释性，语义召回能力不在本轮声明范围内。
